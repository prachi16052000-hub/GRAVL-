GRAVL storefront - static front-end preview

Deploy: upload index.html, about.html and the assets folder together to any static host. No build step.
Fonts load from Google Fonts. Banner photos are in assets. The homepage and About page share button styles. About page styles, motion and imagery are in assets.

Placeholders: product illustrations, review text, and form/checkout actions.
This is not a Shopify theme. The Shopify build converts these sections to Liquid.
